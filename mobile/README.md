# Qistas Mobile

Expo React Native starter for the legal services platform.

## Run

```bash
cd mobile
npm install
npm start
```

Set the API URL with `EXPO_PUBLIC_API_URL` when running on a phone:

```bash
EXPO_PUBLIC_API_URL=http://YOUR_COMPUTER_IP:3000 npm start
```

The existing backend still runs from the project root:

```bash
npm run dev
```
